# 图表 UI/UX 与发布归属检查

2026-09-14 · v0.10.0

## 组件调研与选择

- [AntV G2 Tooltip](https://g2.antv.antgroup.com/en/manual/component/tooltip) 与[交互机制](https://g2.antv.antgroup.com/en/manual/core/interaction/overview)：提供可配置提示和图表交互，适合后续复杂交互图表。
- [Apache ECharts 无障碍能力](https://echarts.apache.org/handbook/en/best-practices/aria/)：支持自动描述和图案等非颜色编码。
- 本版保留本地 SVG 数据渲染，新增统一交互模块。现有模块已覆盖历史快照、缺失断线、真实零值和多平台分组；替换渲染库仍需要迁移这些业务语义。统一模块使用本地静态资源，不依赖 CDN。

## 检查发现与修复

| 优先级 | 发现 | 本版处理 |
| --- | --- | --- |
| P1 | 数据点只有原生 title，无法可靠即时查看数值与时间 | HTML 浮层，悬停、聚焦、点击均可查看；显示原始数值、日期、平台及采集来源 |
| P1 | 数据点小，鼠标难以命中 | 鼠标接近节点即可触发；键盘聚焦、Enter/Space 触发，Escape 关闭 |
| P1 | 窄窗口提示易被裁切 | 浮层附着当前页面并按可视区域定位；滚动、缩放和节点移除后清理 |
| P2 | 坐标缩放后过小、颜色对比不足 | 调整坐标字号、时间刻度、网格线与系列色；系列色对白底对比均超过 3:1 |
| P2 | 指针移动反复创建提示内容 | 同一节点复用内容，缓存节点范围 |
| P1 | 发布链接归属可为空 | 官方链接强制选题；达人链接强制 KOL 和 Campaign；界面、Agent 工具说明和数据层共同约束 |
| P1 | 历史无归属数据与新校验不兼容 | 历史记录仍可读取，列表提供“待绑定”筛选；编辑链接时补齐，禁止猜测归属 |

保持原有多图表配置、筛选、缺失断线、真实零值和数据明细。归档被发布链接引用的选题、达人或 Campaign 会被阻止，需先处理引用。

## 验证范围与边界

隔离数据目录中验证官号/达人保存、必填校验、后端拒绝无归属链接、浮层鼠标/键盘交互及 1100px/400px 视口边界。测试数据不写入用户正式数据目录。自动化测试覆盖快照与数据模型、归属规则及交互。

本版未重启用户实际 DSH Desktop；需要重启加载后确认宿主内表现。历史链接的业务归属必须由用户确认，不自动批量分配。
